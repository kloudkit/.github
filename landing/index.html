Kloud Workspace

Configured development

Docs for Kloud Workspace Kloud Workspace on GitHub

What it is
A batteries-included, pre-configured development workspace inside a Docker container: run customized VS Code in the browser or over SSH.
Ships as
Container image
Try it
docker run -p 8080:8080 \
  ghcr.io/kloudkit/workspace:latest

TestShed

The support crew for your test bench

Docs for TestShed TestShed on GitHub

What it is
A pytest plugin that hands your tests real Docker containers and Playwright browsers as fixtures.
Ships as
Python package
Try it
  1. pip install testshed
  2. pytest --shed --shed-image=ghcr.io/acme/app

Looking Glass

See exactly what is hitting your service

What it is

Ships as

  ghcr.io/kloudkit/looking-glass:latest

Portico

Many services, one front door

Docs for Portico Portico on GitHub

What it is
Run every service of a web app and put one origin in front of them: one port, no CORS.
Ships as
Linux binary or Go module
Try it
  1. go install github.com/kloudkit/portico@latest
  2. portico init && portico up
